## 5. 实际安装过程

1. 实时读取官方安装文档和 `pyproject.toml`，确认 Agent Reach 1.5.0 需要 Python 3.10+。
2. 按官方推荐安装 pipx 1.15.0；Homebrew 同时提供 Python 3.14.6。
3. 直接由 pipx 从 GitHub 安装时，`files.pythonhosted.org` 下载运行依赖极慢。没有修改项目目录，也没有使用 `sudo`。
4. 将 Agent Reach 官方源码包下载到 `/tmp`，从清华 PyPI 镜像下载同版本依赖并构建 wheel，再由 pipx 离线安装。
5. `agent-reach --version` 返回 `Agent Reach v1.5.0`。
6. dry-run 显示基础安装将配置 gh CLI、mcporter/Exa 和基础渠道；随后执行正式安装。
7. 基础组件版本：gh 2.96.0、mcporter 0.12.3、OpenCLI 1.8.6。
8. 为用户指定的小红书来源额外安装 `opencli,xiaohongshu` 渠道。OpenCLI daemon 已运行，但 Chrome 扩展未连接。
9. 安装器最初在项目根目录生成 `config/mcporter.json`；已迁移到 `/Users/liuxin/.agent-reach/config/mcporter.json` 并移除项目内空目录。后续调用使用 `mcporter --config /Users/liuxin/.agent-reach/config/mcporter.json ...`，避免依赖当前工作目录。

安装期间没有记录 Token、Cookie 或密码。`~/.local/bin` 不在默认 PATH，因此脚本和定时任务应使用绝对路径或显式 PATH；这不影响 pipx 隔离环境的长期运行。

## 7. 平台覆盖结论

- Agent Reach 全局 doctor：5/15 个通用渠道直接可用；该数字包含用户不需要的平台，不能作为本项目的成功指标。
- 用户限定的六个平台中：4 个 `PASS`、2 个 `PARTIAL`。
- 按预先设定的严格门槛，当前总体判定仍为**可作为辅助调研工具**；日常使用价值已经满足，但知乎时效筛选和脉脉真实面经质量仍需改善后才能升级为主要工具。
- 正式材料严格限制在六个平台；GitHub、V2EX、RSS、Twitter 等即使已具备能力也不进入本项目题库。

1. 优先级建议：牛客真实面经 > 掘金知识总结 > B站视频材料 > 知乎经验文章 > 脉脉候选题源。

4. 每轮搜索执行来源白名单、前端关键词过滤、URL 去重、时间标记和可信度分级。
5. 脉脉/掘金的营销数字不进入知识结论；真实面经与整理题库分别归档。
