# JavaScript

## 事件循环

- 同步语句在当前调用栈依次执行。
- Promise 的 `.then`/`.catch` 回调进入微任务队列；当前栈清空后，运行时会清空可运行的微任务。
- `setTimeout` 回调在计时满足后才成为可执行的宏任务；它不会保证精确时刻执行。
- 回答顺序题时，逐行标注“同步执行/入微任务/入宏任务”，然后写出调用栈清空后的队列顺序。

**项目映射**：事件配置、网络请求和预览异步更新需要明确加载、成功、失败与取消状态；不能将时间顺序假设为固定延迟。

## 作用域、提升与暂时性死区

- `var` 是函数作用域；声明会提升并初始化为 `undefined`，所以声明前读取不会抛错，但常造成难以定位的 bug。
- `let`/`const` 是块级作用域。它们的绑定在块开始时已存在，但从块开始到声明语句执行前属于暂时性死区（TDZ），读取会抛 `ReferenceError`。
- `const` 必须声明时初始化，之后不能重新绑定变量；若值是对象，仍可修改对象内部属性。
