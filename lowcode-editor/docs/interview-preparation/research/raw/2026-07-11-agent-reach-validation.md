## 可用于后续训练的信息

### 牛客样本发现

- 面试越来越重视项目实现与简历一致性；简历写 IndexedDB、实际却使用 localStorage 会被现场识别。
- 项目追问可能沿离线缓存边界、协同冲突、CRDT、Web Worker 大文件处理、虚拟滚动和内存泄漏连续深入。
- 高频基础包括事件循环、React Hooks、TypeScript、缓存、Webpack、移动端适配和现场编程。
- 候选人复盘本身可用于建立“易错点—补强任务—复练”闭环。

### 掘金样本发现

- 可快速收集 React Fiber、Hooks、TypeScript、Vite/Webpack、性能、工程化、Coding 和项目决策问题。
- AI 前端可围绕 Context、结构化生成、质量保障、测试和人工 Review 展开。
- 文章中的“能力占比”“效率提升倍数”“面试通过率”等数字缺少可靠证据，不能直接用于市场结论。

### B站样本发现

- 搜索 API 能提供标题、UP 主、BV 号、描述、发布时间戳、播放/收藏/点赞及标签。
- 能找到 React 面试、TypeScript、低代码项目和调试类视频。
- 大量结果包含“薪资暴涨”“几天吃透”“留言领取资料”等营销措辞，需要基于作者、互动、时长和内容抽样过滤。

### 知乎样本发现

- 可找到按轮次记录的完整前端面经，并保留技术追问和候选人反思。
- 代表样本覆盖浏览器、网络、HTTP、缓存、事件、BFC、Vue、TypeScript、模块化、项目与算法。
- Exa 对年份限制执行不严格，定时任务不能仅依赖查询词判断时效。

### 脉脉样本发现

- 页面正文可以读取，能获取大量前端场景题，包括请求并发、监控、灰度、微前端、性能、低代码协议和渲染器。
- 当前样本声明可能整编自互联网并带外部资料导流，应作为候选题线索，不作为真实公司面试事实。
